# Конспекты лекций

Рабочая директория для превращения записей онлайн-лекций (захват экрана через OBS)
в структурированные конспекты на Typst.

Один «квант» работы — одна лекция. Результат — `lecture.typ` (и скомпилированный
`lecture.pdf`) в директории лекции.

## Структура

```
template.typ            общий шаблон Typst (импортируется каждым lecture.typ)
<курс>/<NN>/            одна директория на лекцию
  sad/                 «Статистический анализ данных»
  moio/                «Методы оптимизации и исследование операций»
    01/  02/  ...      номер лекции
```

Исходные `*.mp4` (сырой захват OBS) лежат в корне.

### Что внутри директории лекции

Входные данные:

| файл | что это |
|------|---------|
| `transcript.txt` | транскрипт Whisper, строки `[начало-конец]  текст`, русский |
| `1.png … N.png`   | скриншоты слайдов по порядку показа |
| `lecture.ogg`      | извлечённая звуковая дорожка |
| `output*.mp4`      | обрезанное видео |

Результат: `lecture.typ` → `lecture.pdf`.

Нумерация PNG может расходиться с номерами страниц в самой презентации и иметь
пропуски (например, в `moio/01/` нет `22.png`).

## Компиляция

```sh
typst compile --root . sad/01/lecture.typ      # -> sad/01/lecture.pdf
typst watch   --root . sad/01/lecture.typ      # пересборка при сохранении
```

`--root .` (корень репозитория) обязателен: `lecture.typ` делает
`#import "../../template.typ"`, и без указания корня Typst считает это выходом
за пределы проекта.

Typst v0.15.1. Используется встроенный шрифт «New Computer Modern» — ставить
ничего не нужно.

## Шаблон

```typ
#import "../../template.typ": *
#show: doc => lecture(
  title: "Название лекции",
  course: "Название курса",
  number: 1,
  date: "01.09.2026",
  doc,
)
```

Доступные окружения:

- `#definition(title: [...])[...]`, `#theorem(...)`, `#lemma(...)`, `#example(...)`
  — авто-нумеруемые цветные блоки.
- `#note[...]` — серый блок «Устное пояснение:» для сказанного вслух, чего нет
  на слайдах.
- `#neq(content, label-name: none)` — формула с номером справа.

### Изображения слайдов

`image()` внутри `template.typ` ищет пути относительно самого шаблона, а не файла
лекции. Поэтому в `lecture.typ` заводится локальный помощник:

```typ
#let slide-fig(path, caption: none, width: 80%) = figure(
  image(path, width: width), caption: caption, supplement: "Слайд",
)
```

## Полный пайплайн: от видео до конспекта

### 1. Запись

Захват экрана лекции через OBS → `2026-09-01 13-33-15.mp4` в корне репозитория.

### 2. Извлечение звука (ffmpeg)

Видео для расшифровки не нужно — вытаскиваем моно-дорожку 16 кГц в Opus
(компактно, и ровно то, что ест Whisper):

```sh
ffmpeg -i "2026-09-01 13-33-15.mp4" -vn -ac 1 -ar 16000 -c:a libopus -b:a 16k \
  moio/01/lecture.ogg
```

- `-vn` — выбросить видео
- `-ac 1` — свести в моно
- `-ar 16000` — частота дискретизации 16 кГц
- `-c:a libopus -b:a 16k` — кодек Opus, битрейт 16 кбит/с

### 3. Расшифровка (Whisper, Google Colab)

`lecture.ogg` загружается в Colab с GPU-рантаймом, расшифровывается
`faster-whisper` (`large-v3`), результат — `transcript.txt` со строками
`[начало - конец] текст`:

```python
!pip install faster-whisper

from faster_whisper import WhisperModel

model = WhisperModel("large-v3", device="cuda", compute_type="float16")

file_name = "lecture.ogg"
segments, info = model.transcribe(file_name, beam_size=5, language="ru")

full_text = ""
for segment in segments:
    full_text += f"[{segment.start:.1f}s - {segment.end:.1f}s] {segment.text}\n"

with open("transcript.txt", "w", encoding="utf-8") as f:
    f.write(full_text)
```

Скачать `transcript.txt` из Colab и положить в директорию лекции.

> Whisper на этих записях к концу файла (а иногда и в начале) вырождается в
> повторяющийся мусор — «Добавил субтитры DimaTorzoK», «Субтитры создавал
> DimaTorzok», «Продолжение следует». Эти строки игнорируются на шаге 5.

### 4. Слайды

Скриншоты слайдов презентации сохранить в директорию лекции по порядку показа:
`1.png`, `2.png`, … `N.png`. Нумерация — сквозная по порядку в лекции, не по
номерам страниц в самой презентации; пропуски допустимы.

### 5. Генерация конспекта (Claude Code)

Открыть Claude Code в директории лекции и вставить промпт из [`prompt.md`](prompt.md).
Claude читает транскрипт и слайды, пишет `lecture.typ`, компилирует и проверяет
рендер.

### 6. Компиляция

```sh
typst compile --root . moio/01/lecture.typ      # -> moio/01/lecture.pdf
```

## Принципы конспекта (шаг 5, кратко)

1. Сопоставление транскрипта и слайдов — **по смыслу**, не по номерам.
2. Термины, определения, формулы, теоремы, таблицы, код — дословно со слайдов.
   Конфликт со слайдом решается в пользу слайда.
3. Пояснения и связки — из речи, вычистив слова-паразиты, повторы, оффтоп.
4. Сказанное вслух, чего нет на слайдах, → `#note[...]`.
5. Схемы, которые не пересказать текстом, → PNG через `slide-fig`.
6. Заголовки `=`/`==`/`===` повторяют структуру разделов на слайдах.
7. Галлюцинации Whisper игнорируются.
