# Промпт для генерации конспекта — `inf/02`

Открыть Claude Code в корне репозитория (или в `inf/02/`) и вставить текст ниже.

---

Собери конспект лекции в Typst на основе материалов в директории `inf/02/`.

**Курс:** «Теория информации», лекция № 2, дата 14.09.2026.
**Тема:** «Энтропия. Свойства энтропии».
**Образец оформления:** `inf/01/lecture.typ` — тот же курс, повторяй его стиль
(шапка, комментарий-преамбула, `slide-fig`, плотность `#definition`/`#note`).

**Входные данные:**

- `transcript.txt` — транскрипт с таймкодами `[start-end] текст` (Whisper, `large-v3`).
  Есть ошибки распознавания, оговорки, повторы, слова-паразиты. Строки-мусор
  («Добавил субтитры DimaTorzoK», «Субтитры создавал DimaTorzok», «Продолжение
  следует») полностью игнорируй.
- `Лекция 2. Энтропия. Свойства энтропии.pdf` — презентация, 17 страниц. Слайдов в
  PNG **нет** — читай PDF напрямую (Read с `pages`), постранично и целиком. Это
  **эталонный источник** терминов, формул, определений, свойств, таблиц: если
  формулировка в транскрипте расходится со слайдом — бери со слайда.
- `hw.png` — отдельный скриншот слайда «Домашнее задание» (три задачи про урны с
  шарами); тот же слайд — страница 13 PDF.

**Задача:**

1. Прочитай `transcript.txt` целиком и все 17 страниц PDF по порядку, посмотри `hw.png`.
2. Сопоставь фрагменты транскрипта со слайдами **по смыслу**, а не по номерам —
   тайминг слайдов не синхронизирован с речью.
3. Составь связный структурированный конспект:
   - слова-паразиты, повторы, оффтоп (тест, чат, оргвопросы, сдача ДЗ вместе с
     конспектом) — убрать;
   - формулы, определения, свойства энтропии, таблицы — переносить **дословно со
     слайдов** в Typst-нотации (`$...$`, `#table`, `cases(...)`);
   - важное, что лектор сказал вслух и чего нет на слайдах (интуиция про
     неопределённость, монетку, канал связи; пояснения к выводу формулы Хартли /
     Шеннона; обсуждение единиц измерения), — оформлять как `#note[...]`;
   - схемы, графики (например, график энтропии двоичного источника от $p$), которые
     не пересказать текстом, — вставлять картинкой. Для этого вырежи нужную страницу
     PDF в PNG (`pdftoppm -f N -l N -r 150 -png "<pdf>" slide` → `slide-N.png`,
     см. `inf/01/slide-*.png`) и подключай через локальный помощник `slide-fig`;
   - **домашнее задание** — отдельный раздел `= Домашнее задание` в конце:
     условия всех трёх задач переписать с `hw.png` дословно (текстом, не картинкой);
     задачи № 1 и № 2 лектор разобрал на лекции (последние ~25 минут транскрипта) —
     оформить их решения через `#example`; задача № 3 оставлена на самостоятельное
     решение — привести только условие и отметить это;
   - если слайд внутренне противоречив или числа в разборе расходятся с условием —
     следуй условию задачи и транскрипту, а расхождение отметь `#note`-ом.
4. Это конспект, а не расшифровка: не пересказывай всё дословно, но не теряй
   существенное.
5. Заголовки `=`/`==`/`===` повторяют структуру разделов на слайдах.

**Оформление:**

- Шаблон — `../../template.typ`. Заголовок файла:
  ```typ
  #import "../../template.typ": *
  #show: doc => lecture(
    title: "Энтропия. Свойства энтропии",
    course: "Теория информации",
    number: 2,
    date: "14.09.2026",
    doc,
  )
  ```
- Для картинок слайдов заведи локальный помощник (в самом шаблоне пути не резолвятся
  относительно файла лекции):
  ```typ
  #let slide-fig(path, caption: none, width: 80%) = figure(
    image(path, width: width), caption: caption, supplement: "Слайд",
  )
  ```
- Окружения шаблона: `#definition(title: [...])[...]`, `#theorem`, `#lemma`,
  `#example`, `#note[...]`, `#neq(...)`.
- Ловушки Typst 0.15.1: внутри `cases(...)` не писать диапазоны через запятую
  (`i = 1, ..., m` рвётся на строки) — писать `i = 1 ... m`; нет `angle.l`/`angle.r` —
  скалярное произведение писать `bold(c)^T bold(x)`; `#h(...)` вплотную к `(`
  парсится как вызов. Логарифмы — `log_2`, `ln`; суммы — `sum_(i=1)^n`.

Результат сохрани в `inf/02/lecture.typ`. Скомпилируй
(`typst compile --root . inf/02/lecture.typ`) и проверь, что собирается без
ошибок и предупреждений.
