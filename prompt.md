# Промпт для генерации конспекта

Открыть Claude Code **в директории лекции** (`sad/02/`, `moio/03/` и т. п.) и вставить
текст ниже. Материалы (`transcript.txt`, `1.png … N.png`) должны уже лежать в этой
директории — см. пайплайн в `README.md`.

---

Собери конспект лекции в Typst на основе материалов в текущей директории.

**Входные данные:**

- `transcript.txt` — транскрипт с таймкодами `[start-end] текст` (Whisper, `large-v3`).
  Есть ошибки распознавания, оговорки, повторы, слова-паразиты. Местами (обычно в
  конце файла, иногда в начале) вырождается в повторяющийся мусор — «Добавил субтитры
  DimaTorzoK», «Субтитры создавал DimaTorzok», «Продолжение следует». Эти строки
  полностью игнорируй.
- `1.png … N.png` — слайды презентации по порядку показа. Нумерация сквозная, могут
  быть пропуски. Это **эталонный источник** терминов, формул, определений, теорем,
  таблиц и кода: если формулировка в транскрипте расходится со слайдом — бери со
  слайда.

**Задача:**

1. Прочитай `transcript.txt` целиком и просмотри все `*.png` по порядку.
2. Сопоставь фрагменты транскрипта со слайдами **по смыслу**, а не по номерам —
   тайминг слайдов не синхронизирован с речью.
3. Составь связный структурированный конспект:
   - слова-паразиты, повторы, оффтоп — убрать;
   - формулы, определения, теоремы, таблицы, код — переносить **дословно со слайдов**
     в Typst-нотации (`$...$`, `#table`, `cases(...)`);
   - важное, что лектор сказал вслух и чего нет на слайдах, — оформлять как `#note[...]`;
   - схемы и диаграммы, которые не пересказать текстом, — вставлять картинкой через
     локальный помощник `slide-fig` (см. ниже), а не описывать словами;
   - если часть лекции есть на слайдах, но отсутствует в аудио (транскрипт начинается
     не с начала) — восстанови этот раздел по слайдам и отметь это `#note`-ом в начале;
   - если слайд внутренне противоречив (например, в блоке «Решение» числа из другой
     задачи) — следуй условию задачи и транскрипту, а расхождение отметь `#note`-ом.
4. Это конспект, а не расшифровка: не пересказывай всё дословно, но не теряй
   существенное.
5. Заголовки `=`/`==`/`===` повторяют структуру разделов на слайдах.

**Оформление:**

- Шаблон — `../../template.typ`. Заголовок файла:
  ```typ
  #import "../../template.typ": *
  #show: doc => lecture(
    title: "…", course: "…", number: N, date: "ДД.ММ.ГГГГ", doc,
  )
  ```
- Для картинок слайдов заведи локальный помощник (в самом шаблоне пути не резолвятся
  относительно файла лекции):
  ```typ
  #let slide-fig(path, caption: none, width: 80%) = figure(
    image(path, width: width), caption: caption, supplement: "Слайд",
  )
  ```
- Окружения шаблона: `#definition(title: [...])[...]`, `#theorem`, `#lemma`,
  `#example`, `#note[...]`, `#neq(...)`.
- Ловушки Typst 0.15.1: внутри `cases(...)` не писать диапазоны через запятую
  (`i = 1, ..., m` рвётся на строки) — писать `i = 1 ... m`; нет `angle.l`/`angle.r` —
  скалярное произведение писать `bold(c)^T bold(x)`; `#h(...)` вплотную к `(`
  парсится как вызов.

Результат сохрани в `lecture.typ` в этой директории. Скомпилируй
(`typst compile --root . <курс>/NN/lecture.typ`) и проверь, что собирается без
ошибок и предупреждений.
